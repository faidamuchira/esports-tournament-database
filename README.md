# 🎮 Esports Tournament Database (SQL Assignment)
## 📌 Project Overview

This project is a relational database designed to manage an esports tournament system.
It stores information about players, games, tournaments, and matches, and allows analysis through SQL queries.

The database demonstrates key SQL concepts including normalization, joins, aggregate functions, and stored procedures.

## 🎯 Scenario

An esports organization needs a system to:

- Manage registered players
- Organize tournaments for different games
- Track matches between players
- Analyse player performance and activity

This database provides a structured way to store and query this information efficiently.
